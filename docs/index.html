01 · Verify

            
No “should work”. Only output.

            
ship-check detects your toolchain, runs tests, lint, type checks and build, re-reads the whole diff for debug prints, skipped tests and secrets, then maps every acceptance criterion to evidence.

          


> /shipyard:ship
Ship check: READY
- test:      pnpm test → exit 0, 142 passed
- lint:      pnpm lint → exit 0
- typecheck: tsc --noEmit → exit 0
Diff review (7 files, +210 −34)
- Removed: console.log in src/api/user.ts:88
Acceptance criteria
1. Rejects expired tokens → test "rejects expired token"
2. Logs failed attempts → unverified

        

        

          

            
02 · Debug

            
Root cause, then a regression test.

            
bug-hunt makes Claude reproduce the failure, rank hypotheses, instrument one at a time and bisect regressions. After three failed fixes it stops and questions its assumptions instead of guessing again.

          


> /shipyard:fix-issue checkout total off by one cent
Repro: fails 10/10 with cart fixture #4
Hypotheses (ranked)
1. float rounding in applyDiscount  ← testing
2. tax computed before discount
Root cause: src/cart/price.ts:41 rounds per line
Fix: integer cents end to end
Regression test: failed before, passes after

        

        

          

            
03 · Guard

            
Some commands should never run unasked.

            
Hooks run before every shell command and file edit. They block force pushes, git reset --hard, rm -rf ~, curl | sh, DROP TABLE, terraform destroy, edits to .env and lockfiles, and API keys written into code.

          


● Bash(git push --force origin main)
  ⎿ Shipyard blocked this action: force push
    to a protected branch.
● Write(src/config.ts)
  ⎿ Shipyard blocked this action: the new
    content contains what looks like a Stripe
    live key.
Claude: Both actions need your decision. Want me
to push to a feature branch instead?

Questions.

      

        
What do I need?
Claude Code with plugin support and Node.js 18 or newer on your PATH for the hooks. Works on macOS, Linux and Windows, in Bash and PowerShell.

        
Will the hooks get in my way?
They block only commands that destroy data, rewrite shared history, run downloaded scripts or publish packages. Claude gets the reason and asks you. Set SHIPYARD_GUARD=off to turn them off for one session.

        
Does it send my code anywhere?
No. Shipyard is Markdown files and local Node.js scripts with no dependencies and no network calls. You can read all of it.

        
How do I get Pro after paying?
You get a download link right after payment. Unzip it, run /plugin marketplace add <folder> and /plugin install shipyard@shipyard-pro. The README inside covers the plain-files installer too.

        
Can my team use one copy?
One license covers one developer on all their machines and projects, including client work. Each extra developer needs a license.

        
What if it does not help me?
Ask for a refund within 14 days.
